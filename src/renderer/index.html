Telemetry Field Encoding

The competition document specifies an "ACCELEROMETER DATA" field (§6.3) without defining a complete encoding for all axes and orientation angles in a single field. This application uses the encoding: ax;ay;az;roll;pitch;yaw (semicolon-separated within the CSV field). This must match your flight firmware's encoding. Update the configuration if your firmware uses a different format.
